# Claim Classification Standard

MINCO separates numerical effect size from inferential support.

- `validated_advantage`: the candidate has the favorable paired mean and the 95% bootstrap interval for the paired mean difference excludes zero.
- `descriptive_advantage`: the candidate has the favorable paired mean, but the interval includes zero.
- `no_observed_advantage`: the candidate does not have the favorable paired mean.

All current policy evidence is generated from the synthetic Meridian reference network. Statistical support within that experiment is not evidence of real-hospital impact.
