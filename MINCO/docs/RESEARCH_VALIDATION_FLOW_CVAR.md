# FLOW-CVaR Research Validation Contract

**Null hypothesis H0.** On a common patient-flow forecast and surge-scenario set, FLOW-CVaR does not reduce tail recourse loss relative to expected-cost-only capacity planning.

The governed reference uses a row-stochastic Markov patient-flow model over H1, H2, and EXIT, then a two-hospital stochastic MILP with surge beds, flex-staff-equivalent capacity, transfer capacity, diversion/deferral recourse, and CVaR. All reference evidence is synthetic algorithmic validation; it is not clinical validation or a causal patient-outcome claim.
