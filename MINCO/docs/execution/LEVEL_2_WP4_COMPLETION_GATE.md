# Level 2 WP4 — Benchmark, Registry, and Completion Gate

This work package closes the Validated Analytical Core only when:

1. WP1, WP2, and WP3 reports are present and passed.
2. Every referenced run manifest exists and matches its recorded SHA-256.
3. The synthetic benchmark passes internal consistency checks.
4. The asset registry contains versioned hashes and preserves the synthetic-only claim boundary.
5. All four predictive tasks have explicit governance decisions.
6. Approved models are limited to the synthetic reference case.

Passing this gate authorizes Level 3 integration work. It does not establish external or clinical validity.
