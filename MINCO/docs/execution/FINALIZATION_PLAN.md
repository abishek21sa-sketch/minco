# MINCO Finalization Plan — Three Releases

## Phase 1 — Mathematical Hospital Engine

Markov/MMPP demand regimes, CTMC patient flow, probabilistic/survival ML, queueing and conservation mathematics, common-random-number Monte Carlo, two-stage stochastic MILP, CVaR, Progressive Hedging, rolling-horizon reoptimization, independent solver/oracle validation, and cost-aware Claude routing foundation.

## Phase 2 — Native Hospital Operations Workstation

Flutter/Dart Windows application, Protocol Buffers/gRPC, DuckDB/Parquet replay, canonical hospital events, persisted state reconstruction, Census Board, Patient Flow Theatre, Monte Carlo Room, Intervention Composer, current/operator/MINCO policy comparison, and the evidence-grounded Claude Decision Review Board.

## Phase 3 — V1.0 Hardening and Closure

Performance/scalability tiers, dependency cleanup, warnings, observability/security boundaries, technical methods, final README/screenshots, Windows packaging, exact clean-extraction validation, minimal laptop acceptance, secret scan, GitHub `v1.0.0`, then development stops.

## External boundary

Real-hospital historical/clinical validation cannot be manufactured. The V1 software and calibration pathway can be complete while external validation remains explicitly pending.
